# Enuma Playwright Automation

토도스쿨(TodoSchool) 웹 서비스를 대상으로 Playwright와 Pytest를 활용하여
웹 UI 자동화 테스트를 구축하는 프로젝트입니다.

## Tech Stack

- Python 3.14
- Playwright
- Pytest
- pytest-playwright
- GitHub Actions
